# Tamil Nadu Visual Prompting Project

This project contains a structured JSON prompt designed for AI image generation focused on the cultural, architectural, and natural beauty of Tamil Nadu, South India.

## Files

- `tamil_prompt.json` — A detailed prompt specification that defines the visual composition, subject matter, setting, and aesthetic style for generating an image.

## Project Purpose

The JSON prompt is built to help generate a cinematic, photorealistic visual of Tamil Nadu using a multi-layered artistic structure. It captures:

- heritage architecture and temple grandeur
- traditional farming and village life
- cultural activities and hospitality
- scenic landscapes and natural beauty
- rich color palettes and cinematic lighting

## Prompt Structure

The prompt is organized into the following sections:

### 1. Subject
Defines the main visual elements, including:

- ancient Tamil cities and traditions
- Bharatanatyam performance in temple courtyards
- temple architecture and Chettinad palace details
- agricultural landscapes and rural life
- cultural hospitality and cuisine

### 2. Composition
Describes how the scene is framed and layered:

- wide-angle cinematic framing
- foreground, midground, and background depth
- low-angle perspective emphasizing temple scale

### 3. Action
Captures human activity and environmental mood:

- farming and daily village life
- scholars writing on palm leaves
- dancers in motion
- mist, incense, and warm breeze

### 4. Location
Sets the geographic and contextual scene:

- Tamil Nadu, Southern India
- Kaveri river basin region
- historical city environment with temples, markets, and traditional homes

### 5. Aesthetic
Defines the visual style:

- temple gold, terracotta red, emerald green, turmeric yellow, granite grey
- golden-hour lighting
- ultra-realistic rendering
- cinematic atmosphere and fine details

## Usage

Open `tamil_prompt.json` and use its values as a prompt input for AI image generators such as text-to-image tools. You can customize the text to suit a specific mood, location, or artistic direction while preserving the overall Tamil Nadu cultural theme.

## Example Use Case

This prompt is suitable for generating visuals such as:

- a heritage festival poster
- a tourism advertisement for Tamil Nadu
- a cinematic cultural illustration
- a promotional travel image featuring temples, nature, and tradition

## Notes

The prompt is intentionally detailed and structured to improve image consistency and artistic clarity. It can be modified for different output styles, such as more realistic, cinematic, stylized, or high-detail storytelling visuals.
